# Student Management System 🎓

A Python CLI application to manage student records
with full CRUD functionality.

## Features
- Add new students
- View all students
- Update student details
- Delete student records
- Search by name or roll number

## Tech Stack
- Python
- File Handling

## How to Run
```bash
git clone https://github.com/Chanchal-Yadav-06/student-management-system-in-python
cd student-management-system-in-python
python main.py
```
